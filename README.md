<div align='center'>
    <h1>miniloft</h1>
    <h3>a tiny open-source version of loft</h3>
</div>

<br>

To use miniloft, ensure you have:
- [Bun](https://bun.sh) (v1.3.14 and up supported)
- Chrome/Chromium for rendering item thumbnails (set `CHROMIUM_PATH` if it isn't in a standard location)

<br>

Then, run:
```bash
git clone https://github.com/yolkop/miniloft
cd miniloft
bun install
bun .
```

miniloft will then run the logic required to download data and provide you with a Cloudflare-hosted URL with the assets!
